# GEarheads Website

Public website for FTC Team #16460, the GEarheads — a student-led FIRST Tech Challenge robotics team from Brookfield, Wisconsin.

React + TypeScript + Vite, styled-components. See `CLAUDE.md` for stack/conventions, `DESIGN.md` for the design system, `PRODUCT.md` for audience/positioning, and `TODO.md` for the current build checklist.

```bash
npm install
npm run dev       # localhost:5173
npm run build     # type-check + production build to dist/
npm run preview   # preview the production build
```
